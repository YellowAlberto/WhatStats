💡 ¿Cómo exportar tu chat?

Sigue estos sencillos pasos desde tu teléfono móvil para conseguir el archivo .txt correcto.

Android
  1. Entra al chat o grupo de WhatsApp.
  2. Toca los 3 puntos de arriba a la derecha.
  3. Selecciona Más y luego Exportar chat.
  4. Elige SIN ARCHIVOS
  5. Guarda el archivo en tu dispositivo o envíatelo.
  6. Extrae el archivo .txt y súbelo aquí para analizarlo.
iPhone (iOS)
  1. Entra al chat o grupo y toca el nombre del grupo arriba.
  2. Toca los 3 puntos de arriba a la derecha.
  3. Selecciona Exportar chat.
  4. Elige SIN ARCHIVOS
  5. Guarda el documento en la app Archivos de tu iPhone.
  6. Extrae el archivo .txt y súbelo aquí para analizarlo.

**Nota de Privacidad:** Tu archivo se procesa de forma temporal en el servidor únicamente para generar las estadísticas de esta página. No guardamos el chat, no lo almacenamos en ninguna base de datos ni lo compartimos con terceros; una vez generado el panel, los datos se descartan. Para el resumen del informe PDF, se envían estadísticas agregadas (recuentos, porcentajes, nombres de quienes ya participan en el chat) a la API de Gemini (Google) — nunca los mensajes originales.
